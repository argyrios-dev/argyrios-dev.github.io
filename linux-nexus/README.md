# LINUX NEXUS
Cyberpunk-inspired browser desktop built with vanilla HTML, CSS and JavaScript.

## Run locally
Open `index.html` or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Features
- Desktop shell, live clock, status bar, widgets and dock
- App launcher and quick settings
- Draggable, resizable, minimizable and maximizable windows
- URL browser using an iframe
- Simulated terminal, file explorer, text editor, system monitor and settings
- Responsive layout

## Browser limitations
Some websites block iframe embedding with security headers (CSP or X-Frame-Options). Open those sites in a separate browser tab.

## Important
NEXUS is a front-end desktop simulation, not a real Linux distribution. Terminal commands and system metrics are simulated and do not access the host operating system.
